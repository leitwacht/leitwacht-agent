# Code of Conduct

This project adopts the **Contributor Covenant, version 2.1**, in full and
without modification. The canonical text is published at:

<https://www.contributor-covenant.org/version/2/1/code_of_conduct/>

Translations are available at:

<https://www.contributor-covenant.org/translations/>

By participating in this project — opening issues, submitting merge
requests, commenting in discussions, or interacting on any official
channel — you agree to uphold the Code of Conduct linked above.

## Reporting

To report a Code of Conduct concern, email **security@leitwacht.eu**.
Reports are read by the project maintainers only. We aim to acknowledge
receipt within 3 business days.

For security vulnerabilities, see [SECURITY.md](SECURITY.md) instead —
Code of Conduct reports and security reports go to different inboxes.

## Enforcement

Maintainers will follow the **Enforcement Guidelines** section of the
Contributor Covenant 2.1 (linked above) when responding to reports. The
guidelines describe a graduated response — correction, warning, temporary
ban, permanent ban — applied proportionally to the conduct in question.
